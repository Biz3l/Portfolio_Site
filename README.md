# 🌐 Biz3l Portfolio Site

Landing page de portfólio pessoal, desenvolvida com **HTML, CSS e JavaScript puro**, com foco em visual limpo, identidade própria e interações leves.

## ✨ Destaques

- Seção **About Me** com apresentação pessoal
- Lista de **projetos** com links para repositórios
- Seção de **skills** com ícones (Font Awesome + Devicon)
- Área de **contato** com e-mail, LinkedIn e GitHub
- **Easter egg interativo** no título “Me” (mudança dinâmica de cor)
- Título da aba com mensagens dinâmicas quando o usuário troca de aba
- Layout com **ajustes responsivos** para dispositivos móveis

## 🧰 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES Modules)
- [Font Awesome](https://fontawesome.com/)
- [Devicon](https://devicon.dev/)
- [Google Fonts](https://fonts.google.com/) (Montserrat e JetBrains Mono)

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Biz3l/Portfolio_Site.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Portfolio_Site
   ```
3. Abra o arquivo `index.html` no navegador.

> Dica: você pode usar extensões como **Live Server** no VS Code para desenvolvimento com recarregamento automático.

## 🎯 Objetivo

Este projeto foi criado para apresentar, de forma simples e visual, informações pessoais, projetos e formas de contato, servindo como cartão de visita técnico e criativo.
